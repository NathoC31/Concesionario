# Concesionario

Aplicación ASP.NET Core MVC con Entity Framework Core y SQL Server
para gestionar el inventario de vehículos de un concesionario.

## Tema asignado

- Entidad principal: Marca (Nombre, PaisOrigen?)
- Entidad dependiente: Vehiculo (Modelo, Anio, Precio, MarcaId)
- Rol de gestión: Vendedor
- Rol de consulta: Comprador
